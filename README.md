# 禾苗 AI BOX 产品经理 · 面试手册

- `index.html` — 完整手册（九章业务判断 + 105 题 Q&A + 四章补充素材 + 15 张链路图 + 术语注释）
- `tech-flow.html` — 技术链路图解单独版

## 听题怎么用
手册页里每道 Q69–Q85 的右上角有圆形的 ▶，点了就从「30 秒答」开始播；底部出现播放条，可切上一题/下一题、显示进度。
锁屏、蓝牙耳机、通知栏都能控（Media Session + 真 mp3）。首次需要点一下播放键（浏览器要求手势）。
